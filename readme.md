# Quiz Management System

## Project Overview
The Quiz Management System is a Python-based academic project developed as part of the B.Tech First Year Micro Project at Madhav Institute of Technology & Science (MITS), Gwalior.

The project aims to provide a simple quiz application where users can attempt questions, select answers, and view their quiz results.

## Project Details
- **Project Name:** Quiz Management System
- **Programming Language:** Python
- **Institution:** MITS Gwalior
- **Academic Year:** 2026–2027

## Project Workflow
1. Display the main menu.
2. Select an option to start the quiz or view instructions.
3. Display questions with multiple-choice options.
4. Accept and validate user answers.
5. Check answers and calculate the score.
6. Display the final result and percentage.
